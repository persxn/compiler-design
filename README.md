# Compiler Design: the lab and exam coding book

A study book for the B.Tech Compiler Design lab exam and semester paper: lexical analysers in C and Lex/Flex, finite automata, grammars, top-down and bottom-up parsers, Yacc/Bison programs, syntax-directed translation, three-address code, optimisation and code generation. It builds a small compiler for a language called Tiny along the way.

**Read it online:** https://persxn.github.io/compiler-design/

Every program in the book was compiled and run (GCC 13, flex 2.6.4, GNU Bison 3.8.2), and its real output is pasted below it. Work along in a terminal: each chapter uses its own folder, `~/cdlab/chN`.

Chapters 1–6 have been reviewed. Chapters 7–10 are complete but still waiting for their review, so a few details may still change.

The chapters are Markdown files in `compiler-design/chapters/`, so they can also be read here on GitHub.
